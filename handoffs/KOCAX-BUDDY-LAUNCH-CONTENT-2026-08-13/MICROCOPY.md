## Foutmeldingen

- Geen internetverbinding. Controleer je netwerk en herlaad de pagina.
- Je hebt de limiet van <<INVULLEN: fair-use limiet>> berichten voor deze maand bereikt. Je kunt weer berichten sturen bij de start van je volgende factuurmaand.
- De actie is niet opgeslagen in het geheugen. Probeer opnieuw op de knop te klikken.
- De betaling is geweigerd door je bank. Voeg een andere betaalmethode toe via je accountinstellingen.

## Lege staten (Empty states)

- Je geheugen is leeg. Sla informatie op vanuit een chatgesprek om het hier te beheren.
- Je hebt geen openstaande taken. Laat Buddy een taak voorstellen in de chat en keur deze goed om je overzicht op te bouwen.
- Dit is een nieuwe sessie. Buddy start zonder context van eerdere gesprekken.
